## Featured project: CloudGuard

**CloudGuard** is a cloud cost and waste advisor. It helps users track cloud resources, set budgets, and find possible cost-saving opportunities.

- 🌐 **Live website:** [cloudguard-b04o.onrender.com](https://cloudguard-b04o.onrender.com)
- 💻 **Source code:** [CloudGuard repository](https://github.com/madhankandoori/cloudguard)
- 🔐 Users can create private accounts and save their own cloud-cost data.
- 📊 The dashboard includes budgets, alerts, cost forecasts, filters, CSV import, and reports.
